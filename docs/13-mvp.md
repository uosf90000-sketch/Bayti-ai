# 13. MVP — النسخة الأولى القابلة للإطلاق

## 1. فرضية الـ MVP (ما الذي نثبته؟)

> **"عائلة سعودية ترفع مخطط منزلها وتحصل خلال دقائق على تصميم كامل بقائمة تسوق حقيقية مُسعَّرة — وتثق بها كفاية لتتصرف بناء عليها (تشتري/تخطط ميزانيتها)."**

كل ما لا يخدم إثبات هذه الجملة يُقطع بلا رحمة.

## 2. داخل الـ MVP ✅

| القدرة | النطاق في الـ MVP |
|--------|-------------------|
| رفع المخطط | PDF, PNG, JPG (DWG/DXF: يُقبل الملف ويُحوَّل — دون محرر) — طابق واحد أو اثنان |
| التحليل | Parser هجين + شاشة مراجعة/تصحيح إلزامية + سؤال المقياس المرجعي |
| الاستبيان | الأسئلة السبعة الأساسية + سؤالان ديناميكيان كحد أقصى |
| الأنماط | الأنماط الثمانية كاملة (نمط عام + استثناء لغرفتين كحد أقصى) |
| مجلس الوكلاء | **الأحد عشر وكيلًا كاملين** — لكن Landscape يعمل فقط عند وجود مساحة خارجية بالمخطط |
| المواصفات | كل عنصر: نوع/مقاس/لون/خامة/كمية/مكان — على مخطط تفاعلي |
| التسوق | 3–5 متاجر سعودية؛ منتج أساسي + بديل أرخص + بديل أفخم لكل عنصر قابل للشراء؛ الباقي بأسعار سوق |
| النسخ | اقتصادي / متوازن / فاخر — تبديل فوري |
| التكلفة | لكل غرفة/قسم/إجمالي + مقارنة بالميزانية + تصدير Excel |
| الصور | صورتان فوتورياليتان لكل غرفة رئيسية، موجهتان بهندسة الغرفة |
| الفيديو | Slideshow سينمائي من الصور (60–90 ثانية) بموسيقى وانتقالات |
| 3D | عرض 2.5D تفاعلي للمخطط بالأثاث الموزع (بلا مواد نهائية واقعية) |
| PDF | تقرير عربي كامل: مخطط + تصاميم + مواصفات + قائمة تسوق + تكلفة |
| المحادثة | 6 أنواع تعديل: تغيير قطعة، تغيير خامة/لون، رفع/خفض فخامة غرفة، تغيير أرضية، تعديل إنارة، خفض/رفع ميزانية |
| الحساب والدفع | OTP سعودي + باقة Free (غرفة واحدة كاملة كتجربة) + باقة مدفوعة للمنزل الكامل |
| اللغة | عربي RTL كامل (الإنجليزية بنية جاهزة، إطلاقها بعد الـ MVP) |

## 3. خارج الـ MVP ❌ (مؤجل عمدًا)

| المؤجل | إلى | السبب |
|--------|-----|-------|
| رسم مخطط من الصفر | v2 | المستهدف الأول يملك مخططًا |
| جولة 3D واقعية كاملة / فيديو حقيقي | v2 | تكلفة هندسية عالية؛ الـ slideshow يوصل القيمة |
| تطبيق جوال native | v2 | الويب responsive يكفي للإثبات |
| B2B (مطورون/مصممون) | v2–v3 | يتطلب إثبات B2C أولًا |
| Marketplace منفذين | v3 | يحتاج كثافة طلب |
| متعدد العملات/الدول فعليًا | v2 | البنية جاهزة، التشغيل مؤجل |
| AR | v3+ | إبهار بلا حاجة مثبتة بعد |
| تعديل الجدران/الإنشائي | غير مخطط | خارج الرسالة ومسؤولية قانونية |

## 4. معايير إطلاق الـ MVP (Launch Gates)

1. **دقة:** ≥ 85% من غرف Golden Set تُستخرج صحيحة النوع والمساحة (±10%).
2. **ملاءمة هندسية:** ≥ 95% من قطع الأثاث المقترحة تدخل فعليًا في أماكنها.
3. **تسوق:** ≥ 80% من عناصر الأثاث/الإنارة لها منتج حقيقي متاح بسعر بعمر ≤ 72 ساعة.
4. **زمن:** مخطط → نتائج كاملة ≤ 7 دقائق P95.
5. **تجربة:** 10 مستخدمين غرباء (ليسوا أصدقاء) يكملون الرحلة دون مساعدة، و7+ يقولون إنهم "سيدفعون".
6. **أمان:** pentest خارجي مُغلق الثغرات الحرجة، وعزل مستأجرين مُختبر آليًا.

## 5. مقاييس ما بعد الإطلاق (أول 90 يومًا)

- Activation (رفع → نتائج كاملة) ≥ 60%.
- ≥ 3 تعديلات محادثة لكل مشروع (دلالة انخراط).
- ≥ 25% يصدّرون PDF أو يضغطون روابط شراء (دلالة نية حقيقية).
- تحويل Free → مدفوع ≥ 8%.
- COGS AI لكل مشروع ≤ 30% من سعر الباقة.

## 6. فريق الـ MVP والتقدير

- الفريق: CTO + 2 full-stack + 1 AI/ML + مصمم منتج جزئي.
- المدة: ~24 أسبوعًا (تفصيلها في [Roadmap](08-roadmap.md) مراحل 0–3).
- أكبر بند غير هندسي يبدأ فورًا: اتفاقيات المتاجر + جمع Golden Set.
