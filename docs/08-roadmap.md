# 8. Development Roadmap — خارطة الطريق

> فرضية الفريق المبدئي: 1 CTO + 2 مهندسين full-stack + 1 مهندس AI/ML (يُوظف بنهاية المرحلة 0) + مصمم منتج جزئي.
> المبدأ الحاكم: **كل مرحلة تنتهي بشيء يلمسه مستخدم حقيقي.** لا "بنية تحتية لمدة 6 أشهر".

## المرحلة 0 — التأسيس (أسابيع 1–3)

- [x] الوثائق التأسيسية (هذه الحزمة)
- [ ] Monorepo + CI/CD + بيئة dev بأمر واحد + بيئة staging
- [ ] `design-schema` v1: FloorPlanGraph + AgentReport + MasterDesignDocument
- [ ] طبقة LLM الموحدة (providers, logging, cost tracking)
- [ ] جمع 50 مخططًا حقيقيًا (فلل/شقق سعودية) وبدء توسيم Golden Set
- [ ] قرار قانوني: التواصل مع 3–5 متاجر لاتفاقيات affiliate/feeds (المسار القانوني للكتالوج يبدأ الآن — أطول lead time في المشروع)

**مخرج المرحلة:** مطوّر يشغل المنصة محليًا؛ pipeline فارغ يمر end-to-end بمشروع وهمي.

## المرحلة 1 — العمود الفقري: مخطط → تصميم غرفة (أسابيع 4–10)

- [ ] رفع PDF/PNG/JPG + عارض المخطط
- [ ] Floorplan Parser v1 (Vision-LLM + scale سؤال مرجعي) + شاشة المراجعة والتصحيح
- [ ] Architect AI + Interior Designer AI + Furniture AI (3 وكلاء فقط)
- [ ] Orchestrator v1 (تسلسلي، retries, partial re-run)
- [ ] استبيان + اختيار النمط (الأنماط الثمانية)
- [ ] عرض النتائج: عناصر لكل غرفة بالمواصفات الكاملة على المخطط

**مخرج المرحلة (Milestone A):** مستخدم داخلي يرفع مخططًا ويحصل على تصميم أثاث مُواصف لكل الغرف.
**بوابة قرار:** دقة الـ parsing على Golden Set ≥ 85% غرفًا صحيحة — إن أقل، أسبوعان إضافيان هنا قبل التقدم.

## المرحلة 2 — التسوق والتكلفة (أسابيع 11–16)

- [ ] Catalog Ingestion: 3 متاجر (بدءًا بمن لديه feed/API رسمي)
- [ ] Normalization + Enrichment + Embeddings
- [ ] Shopping AI (مطابقة + بديل أرخص/أفخم) + فلتر صلاحية المقاس
- [ ] Cost Engineer AI + market_rates أولية (بحث ميداني حقيقي لأسعار التشطيب بالرياض)
- [ ] النسخ الثلاث (اقتصادي/متوازن/فاخر)
- [ ] شاشات التسوق والتكلفة

**مخرج المرحلة (Milestone B):** من المخطط إلى قائمة تسوق مُسعَّرة بثلاث نسخ. **هذه لحظة "الوااو" الأولى — نبدأ Private Beta بـ 20 مستخدمًا.**

## المرحلة 3 — اكتمال المجلس + المخرجات البصرية (أسابيع 17–24)

- [ ] بقية الوكلاء: Lighting, Electrical, HVAC, Kitchen, Bathroom, Landscape
- [ ] Merger/Chief Designer + الفحوصات الهندسية الحتمية
- [ ] توليد الصور الفوتوريالية الموجهة بهندسة الغرفة (2 زاوية/غرفة)
- [ ] تقرير PDF عربي كامل
- [ ] فيديو slideshow سينمائي
- [ ] التعديل بالمحادثة v1 (الأوامر الخمسة الأساسية + intent clarification)
- [ ] تسجيل/دخول OTP + باقات + بوابة دفع (مدى/فيزا عبر مزود محلي)

**مخرج المرحلة (Milestone C = MVP كامل):** التجربة الكاملة الموصوفة في الرؤية. **إطلاق Public Beta بالسعودية.**

## المرحلة 4 — الصقل والنمو (أشهر 7–9)

- [ ] 3D تفاعلي في المتصفح (من الـ Graph)
- [ ] تحسين المحادثة (تعديلات مركبة، ميزانية ذكية)
- [ ] توسيع الكتالوج إلى 8–10 متاجر + تحديث أسعار يومي
- [ ] fine-tune نموذج الـ parsing على بيانات التصحيحات المتراكمة
- [ ] برنامج المصممين المستقلين (أداة Pro)
- [ ] قياس وتحسين: Activation, تكلفة AI/مشروع, NPS

## المرحلة 5 — التوسع (أشهر 10–18)

- [ ] الخليج: الإمارات أولًا (متاجر + أسعار + شحن) — البنية متعددة الدول جاهزة أصلًا
- [ ] B2B API للمطورين العقاريين ("اشترِ الشقة مؤثثة")
- [ ] تطبيق جوال (تصوير المخطط بالكاميرا + AR معاينة)
- [ ] Marketplace منفذين (مقاولو تشطيب معتمدون)
- [ ] فيديو جولة 3D حقيقي

## إيقاع العمل

- Sprints أسبوعان؛ demo داخلي كل جمعة sprint.
- **قاعدة الجودة:** لا يُدمج PR بدون مراجعة + evals خضراء.
- **قاعدة التركيز:** أي ميزة لا تخدم مسار "مخطط → قائمة مُسعَّرة" تؤجل حتى Milestone B.

## أكبر مخاطر الجدول (انظر وثيقة المخاطر)

1. دقة parsing المخططات — نبدأ به من الأسبوع 4 لأنه المسار الحرج.
2. اتفاقيات المتاجر — تبدأ قانونيًا من الأسبوع 1.
3. جودة الصور المطابقة للهندسة — نموذج أولي بحثي مبكر في المرحلة 1 بالتوازي.
