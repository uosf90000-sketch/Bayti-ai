# Bayti AI Product Library v1

مكتبة بداية حقيقية لنسخة Bayti AI التجريبية.

المحتوى:
- 6 كنبات حقيقية من IKEA السعودية
- روابط شراء رسمية
- أسعار وحالة توفر وقت الفحص
- مقاسات هندسية
- تصنيف متوازن/فاخر
- JSON + CSV + SQL + TypeScript

مهم:
- الأسعار والتوفر تتغير، لذلك استخدم source_checked_at وأعد التحقق قبل العرض.
- image_url متروك فارغًا حتى يتم اعتماد مصدر صور مرخّص.
- المنتج غير المتاح لا يظهر كخيار أساسي.
